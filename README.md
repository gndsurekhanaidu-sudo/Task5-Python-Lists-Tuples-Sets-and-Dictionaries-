# Task5-Python-Lists-Tuples-Sets-and-Dictionaries-
Python Lists, Tuples, Sets, and Dictionaries

Description

This project demonstrates the four main Python collection data structures: Lists, Tuples, Sets, and Dictionaries. It covers adding, removing, searching, sorting, and updating elements.

Objective

To develop practical skills in handling structured data using Python collections.

Technologies Used

- Python
- Jupyter Notebook

Topics Covered

- Lists: Adding, removing, and sorting elements using "append()", "remove()", and "sort()".
- Tuples: Storing ordered and unchangeable data.
- Sets: Storing unique elements and removing duplicates.
- Dictionaries: Storing key-value pairs and accessing or updating values.

Key Learnings

- Understanding the differences between the four collection types.
- Performing common collection operations.
- Choosing the appropriate data structure for different tasks.

Conclusion

This project provides practical experience with Python collections and their commonly used methods.
